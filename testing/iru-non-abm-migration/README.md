# Migrate Macs that aren't in Apple Business from Iru to Fleet

Plans how to move manually enrolled Macs from Iru (formerly Kandji) to Fleet without wiping them, and compares the
pattern already used at a customer (Iru deploys fleetd, a Fleet policy removes Iru, the end user turns on MDM) with
Fleet's end user migration workflow. Method: `../_framework`.

Status (2026-10-27): plan written, not run. Needs an Iru trial tenant first.
